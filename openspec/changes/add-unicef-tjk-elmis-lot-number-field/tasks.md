## 4. Use case: resolve org unit / product and fetch lot numbers

- [x] 4.1 Create `form/src/main/java/org/dhis2/form/lotnumber/GetLotNumbersUseCase.kt`, header `// EyeSeeTea customization - Lot Number Search Field`:
  - Resolve the event's organisation unit UID and look up its `code` via `d2.organisationUnitModule().organisationUnits().uid(...).blockingGet().code()`.
  - Read the current value of `PRODUCT_DE_UID` for the event via `d2.trackedEntityModule().trackedEntityDataValues().value(eventUid, PRODUCT_DE_UID).blockingGet()` to get the product code.
  - If the product code is null/blank, return a "no product selected" result without calling the repository.
  - Otherwise call `LotNumberRepository` and return the `lotNumbers` list for `(orgUnitCode, productCode)`, or an empty/"not found" result if absent.
